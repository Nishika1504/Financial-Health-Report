## 📌 Project Overview

The **Financial Health Dashboard** is an interactive Power BI dashboard designed to analyze and visualize an individual's financial condition using income, expenses, savings, debt, investments, emergency funds, credit score, financial goals, risk profile, and financial literacy data.

The dashboard converts raw financial data into meaningful visual insights that help users understand financial patterns and monitor important financial indicators.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze monthly income and expenses.
- Monitor savings and savings rate.
- Analyze total and average debt.
- Track investments and investment behavior.
- Understand emergency fund levels.
- Analyze credit score distribution.
- Study financial health scores.
- Compare financial behavior across cities and employment types.
- Analyze financial goals and risk profiles.
- Understand financial literacy levels.
- Provide interactive filtering through Power BI slicers.
